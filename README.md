# music-streamer-platform-27497-27506

This workspace contains the React frontend for the music streaming service.

- Frontend path: music_streaming_service_frontend
- Local development: copy .env.example to .env at the workspace root and adjust values as needed before running npm start within the frontend folder.

Quick start:
1) cd music_streaming_service_frontend
2) npm install
3) cp ../.env.example ../.env
4) npm start

By default, the app runs in mock mode (no backend required). Set REACT_APP_FEATURE_MOCK_API=false and REACT_APP_API_BASE_URL to use a real backend.
